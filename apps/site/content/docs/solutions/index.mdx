These guides begin with the experience you want to create, not with an OfferKit object.
Each guide explains the important choices, dashboard configuration, application calls,
test cases, and operational behavior.

## Help customers buy now

- [Run a promotional code](/solutions/public-promo-code) — use one public code or
  generate unique codes for a campaign.
- [Build an automatic cart discount](/solutions/automatic-cart-discount) — return the
  best eligible discount without making the customer enter a code.
- [Combine discounts safely](/solutions/stacking) — apply multiple codes atomically
  with priority and exclusivity.

## Give customers stored value

- [Issue and accept gift cards](/solutions/gift-cards) — create balance-bearing codes,
  preview spend, accept partial payment, and show the ledger.

## Improve retention and acquisition

- [Launch a loyalty program](/solutions/loyalty) — enroll customers, award points,
  create tiers, and exchange points for rewards.
- [Launch a referral program](/solutions/referrals) — issue stable advocate codes and
  reward both people after a successful conversion.

## Personalize eligibility

- [Target customers with rules](/solutions/targeting) — constrain an offer by customer,
  cart, product, date, usage history, or metadata.

## Choose the right mechanism

| If the experience should… | Build… |
| --- | --- |
| Ask the customer for a memorable code | One discount voucher with a custom code |
| Give each recipient a traceable code | A discount campaign with bulk-generated vouchers |
| Discover the discount from cart context | A promotion campaign with one or more tiers |
| Carry a monetary balance across orders | Gift-card vouchers |
| Accumulate and spend points | A loyalty program |
| Track an advocate and reward both sides | A referral program |

If these distinctions are unfamiliar, read [How OfferKit works](/how-offerkit-works)
before choosing.
