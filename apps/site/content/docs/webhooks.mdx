The [webhook guide](/integrate/webhooks) contains the event catalog, payloads, signature
verification, retries, and replay behavior.

An event is not emitted for every operation. Gift-card spend has no event, and there are
no dedicated loyalty-earning, loyalty-redemption, referral-conversion, or automatic-promotion
events. Store those direct API outcomes in your application and trigger their delivery work there.
