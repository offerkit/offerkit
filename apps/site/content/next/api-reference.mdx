Use [API conventions](/reference/api-reference) for authentication, scopes, pagination,
outcome examples, and the complete decision-reason list.

Your deployment publishes its exact contract at `/api/openapi.json`. REST paths begin
with `/api/v1`; a single-voucher commit is `POST /api/v1/vouchers/{code}/redemption`.
The [developer tools reference](/reference/developer-tools) explains SDK `params`, `body`,
`query`, and patch inputs. [Retries and recovery](/reference/retries-and-recovery) compares
body replay keys, HTTP headers, and source event IDs.
